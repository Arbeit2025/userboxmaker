# userboxmaker（ユーザーボックスメーカー）

Wikipedia の利用者ページで使う「ユーザーボックス」のウィキテキストを、フォーム入力から生成する小さな Web ツールです。単一ファイル Flask アプリ（`app.py`）で、データベースは使いません。入力値はサーバーに保存されません。

これは **Bot ではなく Web 生成ツール** です。生成はこのページの中だけで完結し、Wikipedia への投稿・編集は一切行いません。そのため **Bot 承認は不要** です（貼り付けは利用者自身が手で行います）。

## できること

- 左側の短い文字（例：Wiki）と右側の本文を入力すると、ユーザーボックス風のプレビュー（HTML）を表示
- 色はカラーピッカーで指定（左の背景色・文字色、右の背景色・文字色、枠の色）。カラープリセット8種（あお／みどり／あか／むらさき／オレンジ／さくら／グレー／くろ）も用意
- 入力例プリセット3種（「日本語版に参加」「Python使い」「お茶が好き」）
- `{{Userbox}}` を使ったウィキテキストを2形式で出力し、ボタンでコピー可能
  - **そのまま貼れる版**：利用者ページに直接貼る用
  - **テンプレートページ用**：`<noinclude>` で使い方の説明とカテゴリを付けた版
- 入力中の `|` や `{{` `}}` など、ウィキテキストを壊す文字は `{{!}}` や数値文字参照にエスケープして出力

## 使い方

1. フォームに左側の文字・本文・色を入力し、「生成する」を押す（プレビューで見た目を確認）
2. 出力されたウィキテキストをコピーする
3. 貼り付け先：
   - **そのまま貼れる版** … 自分の利用者ページ（利用者:自分の名前）の編集画面に貼り付けて保存すると、ボックスが表示されます
   - **テンプレートページ用** … 「Template:好きな名前」というページを新規作成して貼り付けると、利用者ページから `{{名前}}` の形で呼び出せるようになります。説明とカテゴリは `<noinclude>` の中にあるため、呼び出し先のページにはボックスだけが表示されます

## ローカル起動

```bash
pip install -r requirements.txt
python app.py
# http://localhost:5000
```

## テスト

```bash
python -m unittest discover -s tests
```

テストはネットワークへの実アクセスを行わず、Flask のテストクライアントで生成出力・エスケープ・異常値の扱いを確認します。

## デプロイ（Render）

`render.yaml` を使って Web Service（Free）としてデプロイできます。起動コマンドは `gunicorn app:app`、ヘルスチェックは `/healthz` です。

## 構成

- `app.py` … 本体（単一ファイル）
- `tests/test_app.py` … unittest
- `requirements.txt` … Flask と gunicorn のみ
- `render.yaml` … Render 用設定

## 注意

- 色は16進数（#RRGGBB）のみ受け付けます。不正な値は既定の色に置き換わります。
- 生成されるカテゴリ（`[[Category:ユーザーボックス]]`）は一例です。貼り付ける先のプロジェクトに実在するカテゴリへ書き換えてください。
